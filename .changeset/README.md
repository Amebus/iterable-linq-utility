# Changesets

Each Markdown file in this folder is a changeset: the bump (`patch`, `minor` or `major`) and a note for the changelog of the next release. Create one with `pnpm changeset`, or with `pnpm changeset --empty` for a change to `src/` that releases nothing.

See the Releases section of the [contribution guide](../documentation/docs/how-to-contribute.md).
